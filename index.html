Featured Project

Small Office Network — Cisco Packet Tracer

A practical network design demonstrating routers, switches, VLAN segmentation, DHCP, IP addressing, inter-VLAN routing and connectivity testing.

VLAN-based routed network

Designed for structured support and administration traffic with centralized addressing.

01 • AddressingPlan separate subnets for VLAN 10 and VLAN 20, with the router providing the default gateways.
02 • VLANs & TrunkCreate VLANs on the switch, assign access ports and configure an 802.1Q trunk toward the router.
03 • DHCP & TestingProvide DHCP scopes for clients, then verify gateway reachability and inter-VLAN connectivity with ping tests.

Representative Cisco configuration

! SW1
vlan 10
 name SUPPORT
vlan 20
 name ADMIN

interface range fa0/1-2
 switchport mode access
 switchport access vlan 10

interface range fa0/3-4
 switchport mode access
 switchport access vlan 20

interface g0/1
 switchport mode trunk

! R1 - router-on-a-stick
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

! DHCP
ip dhcp pool SUPPORT
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1

ip dhcp pool ADMIN
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1

Connectivity validation checklist

  • Confirm PCs receive the expected DHCP address and default gateway.
  • Ping each VLAN gateway from its connected client.
  • Ping between a VLAN 10 client and VLAN 20 client to verify inter-VLAN routing.
  • Use show vlan brief, show interfaces trunk and show ip interface brief to troubleshoot configuration issues.
